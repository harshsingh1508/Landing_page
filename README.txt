BRIGHTSPACE LANDING PAGE - BEGINNER GUIDE
==========================================

WHAT IS INCLUDED?
- index.html : the page structure and text
- style.css  : colors, spacing, layout, responsive design
- README.txt : these instructions

HOW TO OPEN THE PROJECT
1. Extract/unzip this folder.
2. Open the extracted folder.
3. Double-click index.html.
4. It should open in your browser (Chrome, Edge, Firefox, etc.).

HOW TO EDIT THE PROJECT
1. Right-click index.html and choose Open with > Notepad, VS Code, or another code editor.
2. Change the headings, paragraphs, and contact email.
3. Save the file.
4. Open or refresh index.html in your browser to see the changes.
5. To change colors, open style.css and look near the top for:
       --purple: #635bdb;
   Replace that color code with another hex color.
6. Keep index.html and style.css in the same folder so the styling loads correctly.

HOW TO SUBMIT
- Replace the sample text/contact information with your own details.
- Take screenshots of the finished page if your internship asks for proof.
- Submit the project folder or ZIP according to your instructor's instructions.

NOTE
The page uses Google Fonts when internet access is available. It still works without them,
using a standard sans-serif font as a fallback.
